# Авито-бот «Денталия-2»

ИИ-автоответчик для чатов Авито стоматологической клиники «Денталия-2» (Самара, ул. Победы 6).
Отвечает на входящие обращения, доводит до звонка администратору, ставит черновики на одобрение.

**Это отдельный сервис, не часть DENTE CRM.** Зависимости от базы `dental_crm` нет и не планируется.

## Законы проекта

Нарушение любого из них — не баг, а брак. Они закодированы в тестах, а не только описаны здесь.

1. **Ни одна цена не произносится, если её нет в `data/patient-quotes.json` с `quote_allowed: true`.**
   Модель охотно выдумывает уверенные цифры. Проверка — в `brain/guard.py`, поверх текста модели.
2. **Себестоимость не покидает диск.** В `data/ortho-prices.json` цены пациента и закупка клиники
   разделены физически: брекеты пациенту 250 000, закупка 30 000. В промпт уходит whitelist полей.
3. **Бот не ставит диагноз и ничего не обещает.** Ни «у вас пульпит», ни «вылечим без боли»,
   ни гарантий. Из чата этого не видно, а обещание — это претензия.
4. **Всё непонятое уходит человеку, а не пациенту.** Автоответ — белый список (адрес, график,
   парковка). Ошибка в сторону черновика стоит минуты администратора, ошибка в сторону
   автоответа стоит пациента.
5. **Персональные данные пациентов в свою базу не пишутся.** Только `phone_hash`. Номер живёт
   в переписке Авито; дублировать его незачем, а 152-ФЗ это упрощает радикально.
6. **Мгновенных ответов не бывает.** Задержка 40–90 с на первый ответ, дальше со скоростью
   набора. Мгновенный ответ выдаёт бота вернее любой формулировки.
7. **Дожимов не больше двух, оба черновиком.** Третий — это спам и риск аккаунта Авито.

## Что бот не делает никогда

Ставит диагноз · обещает результат · называет цены ортодонтии (не утверждены) · выдаёт личную
почту приходящего врача · торгуется и даёт скидки · задаёт больше двух вопросов подряд · пишет
ночью и в выходные · отвечает на то, чего нет в утверждённом прайсе, придуманной цифрой.

## Устройство

```
capture/  (Node + Playwright)   транспорт Авито: сессия, опрос, отправка
brain/    (Python 3.11)         решения
  gate/     hours, intent       график и белый список — фоллбек, когда LLM недоступен
  llm/                          17 ключей, каскад моделей, кулдауны
  prompt/                       сборка промпта из data/, только разрешённые поля
  store/                        SQLite: дедуп, черновики, перехват, аудит
  tg/                           панель администратора с кнопками
  guard.py                      вето поверх ответа модели
  delay.py                      человеческая задержка
  followup.py                   дожим молчания
  pii.py                        скраббер ПД
data/                           единственный источник правды: цены, факты, график
docs/                           стратегия продаж, плейбук диалога, контракты интерфейсов
tools/                          извлечение прайса из PDF по координатам слов
```

Поток одного сообщения:

```
poll → store.mark_seen (дедуп) → router
         ├ intent.classify       (фоллбек и предохранитель)
         ├ prompt.build_*        (только разрешённые цены)
         ├ llm.complete          (ротация ключей, каскад)
         ├ guard.check           (вето: выдуманная цена → черновик)
         └ delay.plan_reply
   AUTO → send        |    DRAFT → tg.post_draft → кнопки → send
```

Нейронка ведёт диалог, правила её страхуют. У правил две роли: деградированный режим, когда все
ключи в кулдауне, и вето, которое модель не может переопределить. Подробно — `docs/CONTRACTS.md`.

## Запуск тестов

```bash
cd C:\Clinic_MVP\avito-bot
python brain/tests/test_gate.py       # график и белый список
python brain/tests/test_guard.py      # вето
python brain/tests/test_followup.py   # дожим
```

Каждая сюита печатает `ИТОГ: N/M` и возвращает ненулевой код при провале. Сети и ключей не требует.

## Данные

| Файл | Что внутри |
|---|---|
| `data/pricelist-2026.1.pdf` | прайс, который клиника публикует сама (Яндекс.Диск, ссылка с сайта) |
| `data/pricelist-2026.1.json` | извлечение по координатам слов + дефекты исходного документа |
| `data/patient-quotes.json` | собранные цены «за визит» с флагом, разрешено ли произносить |
| `data/patient-prices.md` | то же по-человечески, для владельца |
| `data/clinic-facts.json` | адрес, телефоны, график, что делают и чего больше не делают |
| `data/ortho-prices.json` | ортодонтия: цена пациента отдельно от закупки, произносить нельзя |

Прайс извлечён `tools/extract-pricelist.py` — по координатам слов, потому что `pdftotext -layout`
переливает многострочные названия услуг и сдвигает колонку цен. Все три страницы сверены глазами
по рендеру и перекрёстно подтверждены карточкой Яндекс.Карт.

**Постатейный прейскурант нельзя складывать механически.** Собранная сумма за пульпит
(9,9–19,1 тыс) оказалась завышенной против реальных 7–12 тыс: складывались и лечение канала,
и обтурация, и материалы, хотя на практике это одна процедура. Итоги берутся якорями у клиники.

## Окружение

Секреты только в `.env`, он в `.gitignore`. Образец — `.env.example`. Ни один ключ не должен
попасть в код, лог, файл состояния или текст исключения.

## Развёртывание

Рантайм — ноутбук `192.168.1.34`, каталог `C:\bots\avito-reply`. Там живёт персистентный профиль
Chromium с авторизованной сессией Авито. Причина: официального API у Авито нет (ключи выдаются
только платным кабинетам по заявке), а вебхуки требуют публичного HTTPS, которого у клиники нет.
Сессия должна работать с того же IP, с которого клиника обычно заходит.
